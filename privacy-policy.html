Pixel Color Picker

Política de privacidad

Información clara sobre tus datos.

Pixel Color Picker ayuda a identificar colores y extraer texto desde el contenido visible de Chrome. El procesamiento se realiza localmente en el navegador.

Última actualización: 8 de septiembre de 2026

Responsable

Pixel Color Picker es mantenida por Daniel Felipe Zapata Martinez. Para consultas sobre privacidad, puedes escribir a danielzapatam93@gmail.com.

Qué hace la extensión

Pixel Color Picker permite seleccionar un color visible en pantalla y copiar sus valores HEX y RGBA. También permite seleccionar una región visible de la pestaña activa para extraer el texto que contiene mediante reconocimiento óptico de caracteres, conocido como OCR.

Estas acciones se ejecutan únicamente después de que el usuario inicia de forma explícita el selector de color o la captura de texto. La extensión no monitoriza continuamente las páginas ni funciona como un proceso de vigilancia en segundo plano.

Información que se procesa

Cuando el usuario utiliza la función OCR, la extensión captura temporalmente la parte visible de la pestaña y recorta la región seleccionada. La imagen y el texto reconocido se procesan dentro del navegador mediante Tesseract.js y WebAssembly.

La extensión no envía las capturas, los colores ni el texto reconocido a servidores externos. Tampoco utiliza servicios de analítica, publicidad, perfiles de usuario, cuentas, API keys ni servicios de inteligencia artificial remotos en la versión actual.

Almacenamiento local

Pixel Color Picker puede guardar en el almacenamiento local de Chrome el último color seleccionado y las preferencias del OCR, como el idioma configurado. Esta información permanece en el dispositivo del usuario, no se sincroniza mediante un servidor propio y no se comparte con terceros.

Permisos utilizados

activeTab Permite acceder temporalmente a la pestaña activa después de una acción del usuario para leer sus píxeles visibles y capturar la región seleccionada para OCR.
scripting Permite inyectar temporalmente el selector rectangular y sus estilos en la pestaña activa cuando el usuario inicia la captura de texto.
offscreen Permite ejecutar el recorte de la imagen y el procesamiento OCR en un documento fuera de pantalla, donde Tesseract.js puede utilizar canvas, workers y WebAssembly.
storage Permite guardar localmente el último color seleccionado y las preferencias del OCR.

Código remoto y terceros

La extensión no carga ni ejecuta código remoto. Los archivos JavaScript, WebAssembly, workers y modelos de idioma necesarios para Tesseract.js se incluyen dentro del paquete de la extensión y se cargan desde el propio entorno de Chrome.

Pixel Color Picker no vende, alquila ni comparte información con terceros. Si una versión futura incorporara un servicio externo, esta política se actualizaría antes de introducir ese cambio.

Conservación y eliminación

No se conservan copias de las capturas ni del texto OCR en servidores externos. Para eliminar los datos guardados localmente, el usuario puede borrar los datos de la extensión desde la configuración de Chrome o desinstalar Pixel Color Picker.

Limitaciones

La captura OCR funciona sobre la parte visible de la pestaña y no sobre contenido desplazado fuera del viewport. Chrome puede impedir el acceso a páginas internas o protegidas, como chrome://, la Chrome Web Store y otras páginas del sistema. La precisión del OCR depende de la nitidez, el tamaño, el contraste y el estilo del texto seleccionado.
